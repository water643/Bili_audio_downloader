# B站音频下载器（WebUI）

下载 B站视频音频，转 MP3，支持音量调节、脉冲反馈和通道交叉。

## 安装依赖

    等我找全ww

## 运行

    点击run.bat即可

## 功能

    响度均衡
    蝰蛇音效处理
    多线程下载
    Hi-res下载支持（没测试过不知道）
    收藏夹批量下载
